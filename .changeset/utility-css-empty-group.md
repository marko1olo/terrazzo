A `utility` group whose globs match no tokens no longer discards the remaining groups.

The zero-match guard ended in `break`, which reads like the `break` closing each `case` of the `switch` immediately below it but applies to the enclosing `for…of`. Group entries are sorted by name, so the first group matching nothing stopped every group after it alphabetically — the only sign being a warning naming the empty group, with nothing to say the others had been dropped.
